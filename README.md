# PDFページ結合スクリプト（script.py）の使い方
このスクリプトは、指定したフォルダ内にある複数のPDFファイルを、ファイル名順（昇順）に全ページ結合して1つのPDFファイルを出力します。

（**🔴※　右側の　”Latest”　から最新versionをご利用ください**）

📁 ディレクトリ構成
スクリプト（script.py）と同じフォルダ内に pdfCombination という名前のフォルダを作成し、結合したいPDFファイルを配置してください。

```text
Plaintext
作業用フォルダ/
├── script.py                  # 本スクリプト
├── pdfCombination/           # 結合したいPDFを入れるフォルダ
│   ├── 01_資料A.pdf
│   ├── 02_資料B.pdf
│   └── 03_資料C.pdf
└── merged_all_pages.pdf      # 実行後に自動生成されます
```

## 🚀 使い方
1. 準備
スクリプトと同じ場所に pdfCombination フォルダを作成します。

結合したいPDFファイルを pdfCombination フォルダの中に入れます。

※ファイル名のアルファベット・数字順（昇順）で結合されます。順番を制御したい場合は 01_..., 02_... のように名前をつけてください。

2. 実行
コマンドプロンプトやターミナルでスクリプトのあるフォルダに移動し、以下のコマンドを実行します。
（※script.pyをダブルクリックで実行してもOK）

Bash
python script.py

## 🔀 結合モードの選択機能

スクリプトを実行すると、コンソール（黒い画面）上で結合方法を選択するメニューが表示されます。用途に合わせてモードを切り替えることができます。

### 選択メニュー
```text
========================================
 PDF結合モードを選択してください 
========================================
 1 : 各PDFの「1ページ目」だけを抽出して結合
 2 : 各PDFの「全ページ」をそのまま結合
========================================
番号を入力してください (1 または 2):
```

3. 結果の確認
処理が完了すると、スクリプトと同じフォルダに merged_***_pages.pdf が生成されます。

## 📌 注意点・前提条件
必要ライブラリ: PyPDF2 がインストールされている必要があります。

Bash
pip install PyPDF2

パスの移動: スクリプトをどのPCやフォルダに移動しても、スクリプトの配置場所を基準に自動で相対パス（pdfCombination）を探すため、そのまま利用可能です。
